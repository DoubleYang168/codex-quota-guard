# 隐私与本地数据

Quota Guard 没有独立的云端服务、遥测上传或在线账户系统。它通过本机 Codex 读取账户额度及会话元数据，并使用 Codex 提交续跑。Codex 自身的网络访问与数据处理由其产品行为决定；不能因此宣称整个工作流程离线。

## 保存什么

| 数据 | 用途 |
| --- | --- |
| 配置与会话名单 | 阈值、模式、间隔、选择的会话 |
| 会话标题、UUID、工作目录、轮次与身份摘要 | 准确定位目标，防止旧记录控制新任务 |
| 账户指纹、额度摘要、重置时间 | 避免切换账户后错误恢复 |
| Goal 身份摘要 | 核对原 Goal；不持久化 Goal 正文 |
| 暂停恢复、手动操作与错误事件 | 恢复、去重与人工排查 |
| 控制令牌、管理页链接、锁和诊断文件 | 本机控制、鉴权与故障定位 |

适配器会读取核对所需的会话状态或片段；不等于把全部聊天历史永久保存。状态、错误和诊断仍可能含敏感内容。文件未加密，约 1 MiB 的事件日志会轮换一份；状态和其他诊断文件没有统一的自动过期清理承诺。

## 数据目录

环境变量优先，其次当前安装的 `runtime-home.json`，否则使用当前代码根目录 `.runtime`。源码安装默认固定为源码目录 `.runtime/user`。请保留此目录并做好本机备份，不要提交到 GitHub。

卸载插件不会自动删数据。需要删除时先退出后台、确认无需旧恢复记录，再按 [INSTALL.md](../INSTALL.md) 清理；不要删除正在运行实例的状态。

## 管理页凭证

页面只监听 `127.0.0.1`，随机凭证通过 URL 片段带入页面，后续 API 请求使用专用请求头。不要分享完整链接、控制令牌或包含凭证的终端输出。Host／Origin 校验不能隔离同一 Windows 用户下的恶意程序。

本仓库示例和 README 截图采用模拟会话；发布脚本排除 `.runtime`、研究材料和机器专用指针。启发式扫描不能保证发现所有隐私信息，提交前仍需人工审阅。
