- 增加长调度间隔／过期额度、Goal 快速完成并清除时保守要求检查、验收结果限定到具体版本的测试。

Mac 使用桌面 IPC 的临时状态订阅，不通过 app-tools 进程来源校验通道获取实时状态。安装步骤与能力边界见 [Mac 专用说明](MACOS.md)。

## 可重复的非真实聊天验证

```powershell
npm run check
npm test
npm run package
npm run verify:release
npm run package:source
```

后两项需要 Python 3。测试／check／打包不要求真实账户。`npm run demo` 可验证表单保存、手动按钮与名单，后端全为模拟，不查询真实额度。

在已安装支持的桌面和 CLI 的机器，还可执行 `node scripts/validate-package.mjs`。该脚本使用项目内独立 CODEX_HOME 注册安装并检查工具发现，不运行真实聊天控制；第三方 CLI 自身可能有缓存／日志行为，且不等于桌面 UI 安装已验证。
