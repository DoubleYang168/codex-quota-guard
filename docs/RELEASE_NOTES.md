# 0.4.5 实验版发行说明

本文件是待发布正文模板；发布前按实际结果核对，不代表已创建 GitHub Release。

## 变化

基于 0.4.4 整理首个公开源码目录，保留现有额度监控、指定会话手动控制、自动暂停／恢复调度与管理页面。补充使用、安装、兼容、隐私、贡献、发布说明和模拟截图；增加清洁源码归档、版本检查及 CI 配置。

## 环境

Windows Codex 桌面本地会话、Node.js 22+。无 npm 运行依赖。实验适配 CLI `0.163.0-alpha.10.2`／桌面 `26.1013.4894.0`，及 CLI `0.163.0-alpha.11.2`／桌面 `26.1016.8622.0`。具体检查行为见仓库的兼容性文档。

## 文件和安装

运行包按 INSTALL.md 的“从运行发行包安装”；源码包按“从源码安装”。SHA-256 从各 ZIP 的 `.sha256` 旁文件核对。GitHub 自动生成的源码压缩包也可用于源码安装。

## 验证说明

2026-10-23，Windows／Node.js 22.19.0 环境：公开源码检查通过；66 项测试通过，源码 ZIP 隔离解压后再次 66 项通过；独立构建、运行包与源码包的 CRC／SHA-256／文件一致性校验通过。隔离 CODEX_HOME 注册成功，发现全部 10 个 MCP 工具。模拟页面保存反馈和底部对齐已检查。

未进行真实 Goal 自动恢复验收，未在 GitHub 运行 CI，未在本机运行 Node 24。完整边界见 docs/VALIDATION.md。发布前如有代码变化应按影响重新验证。

## 限制

使用未公开桌面接口，不是 OpenAI 官方项目。不支持普通 ChatGPT 网页聊天或云任务。暂停是中断轮次，恢复是新续跑消息；没有执行快照。采样可能超过阈值；严格 100% 恢复时多个会话可能分批等待。

普通会话控制有原开发环境反馈，但完整真实 Goal“中断 → 自动恢复 → 后续自动轮次”及宿主原生面板显示仍未完成专项验收。此版本按 Pre-release 发布，不承诺所有宿主／新版兼容。
