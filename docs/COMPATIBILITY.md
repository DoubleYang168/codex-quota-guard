# 兼容性

维护日期：2026-10-24。插件版本：0.4.6。

## 范围

要求 Windows 或已验证的 macOS Apple Silicon、当前用户已登录且支持本地插件的 Codex 桌面环境、Node.js 22+。Mac 通过桌面 IPC 获取实时状态；普通 ChatGPT 网页聊天、远程云任务、Intel Mac 和 Linux 桌面控制未支持。

Mac 已核对组合：CLI `0.163.0-alpha.11.2`／桌面 `26.1016.62342`，arm64。协议审阅、真实只读连接、专用普通聊天停止／续跑完成闭环及请求去重通过；受控恢复条件下原 Goal 自动后续轮次、重启去重及新输入保护通过；自然额度重置不在本轮范围，完整边界见 [macOS](MACOS.md)。下表为 Windows 组合。

| CLI | 桌面包版本 | 验证情况 |

| `0.163.0-alpha.10.2` | `26.1013.4894.0` | 已审阅协议，原开发环境有只读连接验证；完整 Goal 自动恢复未验收 |
| `0.163.0-alpha.11.2` | `26.1016.8622.0` | 已审阅协议并做只读连接；原开发环境有普通会话手动控制反馈和一次自动暂停记录；完整 Goal 自动恢复未验收 |

以上是实验适配，不是长期兼容承诺。不要简单修改兼容版本字段来绕过限制。

## 版本检查的实际行为

使用默认基线时，代码接受审阅表中的 CLI；桌面版本可读时，必须与其对应版本一致。桌面包版本无法读取时，允许继续根据 CLI 与后续协议检查判断，同时报告 `desktopVersionVerified:false`。因此 `compatible:true` **不等于桌面版本已经核实**。

Mac 必须读取到桌面版本，且为 arm64；无法读取时禁止控制。显式自定义版本固定值使用精确匹配。真实动作还要通过 IPC 协议、目标拥有者及轮次身份检查。兼容检查通过不代表 Goal 端到端成功。

## 自查

```powershell
node --version
npm run doctor
```

优先使用桌面附带 CLI。可通过 `CODEX_QUOTA_GUARD_CODEX` 显式指定实际 `codex.exe`。doctor 只读，但结果含本机状态和账户摘要，不要原样提交。

## 与官方安装机制的关系

本项目的打包结构、本地 marketplace 说明参照 [OpenAI 官方插件文档](https://developers.openai.com/plugins/build/plugins)，查阅于 2026-10-23。文档支持本地 marketplace 及桌面安装；本仓库额外提供的 CLI 安装脚本依赖上述已验证 CLI 的命令行为。不同宿主界面和缓存布局可能改变，应以本机安装输出为准。

GitHub 开源、本地 marketplace 安装和上架官方公共插件目录是不同事项。本项目没有宣称获得官方审核或上架。
