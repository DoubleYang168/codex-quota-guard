# 使用手册

本 Mac 分支面向 M 系列芯片，首次使用默认观察模式、空名单。安装见 [Mac 安装说明](../INSTALL.md)，验收边界见 [Mac 专用说明](MACOS.md)。Windows 用户请前往 [Windows 版本（main 分支）](https://github.com/DoubleYang168/codex-quota-guard/tree/main)。

## 先认识三个开关

| 控制项 | 作用 |
| --- | --- |
| 宿主的插件连接开关 | 是否加载 MCP 工具；不会可靠终止已启动的独立后台 |
| 启用监控 | 是否执行自动管理规则；停用不打断聊天 |
| 观察／自动控制 | 观察只记录拟执行动作；自动控制才按阈值执行 |

管理页前两个监控选项修改后须点击“保存设置”。规则修改后点击“保存规则”。未保存时会保留本页草稿；整个页面重新加载或离开会丢弃草稿。缓存刷新及另一表单保存不会覆盖当前草稿。

## 选会话

搜索标题、翻页、勾选目标会话，或使用完整会话 UUID 添加。勾选立即保存。只看已加入是显示筛选，不会改变名单。

新名单为空，不会接管全部聊天。加入后后台按已保存的模式和规则判断，不需要另行点击启动聊天。取消选择会取消尚未发送的自动恢复，不会停止聊天。

会话列表来自本地索引；实时运行状态另经桌面连接核对。列表里可见不代表桌面当前已加载该会话。桌面重启后，必要时先打开目标会话一次。

## 阈值与检查

暂停和恢复均使用 5 小时窗口的剩余百分比。恢复阈值必须高于暂停阈值，检查间隔为 15–3600 秒。小数阈值在页面按 0.1 输入。周额度耗尽时不恢复。

后台每个周期检查，页面每 10 秒读取缓存，两者不同。打开页面或刷新会话会读取真实额度，但读取状态本身不等于执行一次阈值控制。

“立即检查”执行**已保存**的规则，在启用自动控制时可以停止或恢复名单内的会话。它会重新判断因新工作而被本周期背景检查跳过的轮次；仍须通过账户、身份、版本、队列及结果不明检查。

示例：暂停 5、恢复 100、间隔 300 表示剩余不高于 5% 时暂停，剩余达到 100% 且其他条件满足时尝试恢复。检查不是连续的，不能保证精确停在 5%。严格 100% 时，多个会话可能分批等待。

## 手动停止和继续

手动按钮不要求先加入名单，也不受观察模式和监控总开关限制。它们仍会检查目标身份、兼容性和任务变化；启动还检查额度等条件。运行中不会重复启动。

手动停止只中断当前轮次，不安排自动恢复。手动继续是在原会话提交新消息，不是恢复 CPU／进程现场；已完成的 Goal 不重新激活。

手动控制会取消本会话未完成的旧自动恢复。如果该会话仍在监控中，后续新轮次继续受规则约束。需要完全手动管理时，先移出名单。

## 恢复记录

| 状态 | 含义／处理 |
| --- | --- |
| `pause_pending` | 已记录暂停意图，正在核对中断；不要重复控制 |
| `waiting_reset` | 等待额度或目标桌面会话可用 |
| `resume_pending` | 正在提交恢复请求 |
| `resume_check` | 已提交续跑，等待执行证据 |
| `goal_check` | 已观察到续跑，继续检查原 Goal 后续轮次 |
| `needs_attention` | 无法证明控制结果，停止自动重发；检查原聊天后决定下一步 |
| `cancelled` | 旧恢复被取消或新任务取代 |

其他完成状态以页面说明为准。看见续跑轮次不代表完整 Goal 后续自动执行已验收。解除结果不明的阻止只表示你已人工检查，不代表前次操作成功，也不会重发控制。取消恢复不会主动继续聊天。

## 命令行

在源码安装目录操作已安装实例，先与安装时的数据目录保持一致：

```sh
$env:CODEX_QUOTA_GUARD_HOME = Join-Path (Get-Location).Path '.runtime\user'
node bin/quota-guard.mjs service-status
node bin/quota-guard.mjs ui
```

自定义过数据目录时，把环境变量设为原来的绝对路径。

| 命令，接在 `node bin/quota-guard.mjs` 后 | 作用 |
| --- | --- |
| `service-status` | 仅读缓存，不启动后台、不查询实时额度 |
| `start` | 启动后台，保留已保存监控开关 |
| `ui`／`ui --no-open` | 启动后台，打开浏览器／只输出带凭证链接 |
| `status` | 按需启动后台，读取真实状态 |
| `configure --enabled`／`--disabled` | 立即保存监控开关，按需启动后台 |
| `configure --observe`／`--live` | 立即保存观察／自动模式 |
| `configure --pause 5 --resume 100 --interval 300` | 立即保存规则 |
| `watch <thread-id>`／`unwatch <thread-id>` | 加入／移出指定会话 |
| `check` | 执行一次已保存规则 |
| `dismiss <episode-id>` | 取消指定恢复，不续跑 |
| `doctor [thread-id]` | 只读诊断，不发停止或续跑 |
| `stop` | 保存监控为停用并退出后台 |

CLI／MCP 的直接配置即时生效，只有浏览器表单需要显式点击保存。退出后重新打开后台仍保持监控停用，核对设置后再 `configure --enabled`。

## 停用、升级与退出

关闭浏览器不会结束后台。停用监控不会中断聊天。退出后台不会自动恢复已暂停聊天。禁用／卸载宿主插件前先退出后台，升级沿用原数据目录，详见 [INSTALL.md](../INSTALL.md)。

## 不连接真实聊天的演示

```sh
npm run demo
```

复制终端的本机链接打开浏览器。演示页顶部明确标记模拟环境，按钮只操作模拟会话。使用独立临时数据目录，不读取真实账户，也不连接 Codex。终端 Ctrl+C 退出。
